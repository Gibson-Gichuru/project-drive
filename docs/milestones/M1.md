# M1 — Open mapping and navigation spike

Status: **in progress — real-world route gate open**, 2026-11-13. Do not begin M2 until M1's acceptance evidence is complete.

## Implemented

- Provider-neutral Android `NavigationEngine`, route/coordinate/maneuver types, route progress, and a remote adapter. MapLibre types are isolated in `map/MapLibreRenderer`.
- A self-hosted Kenya map built with Planetiler/OpenMapTiles and served with Martin, including locally served Noto glyphs and visible attribution. Valhalla supplies driving routes/instructions from the same OSM snapshot. No public tile/geocoding service or vendor key is used.
- Go gateway validates required coordinates and payload sizes, limits upstream time/response size, normalizes Valhalla geometry/maneuvers, and omits route bodies and tile identifiers from ordinary logs. The unauthenticated spike is rejected in production configuration.
- Android map-pin/coordinate destinations, route preview, explicitly simulated playback, manual GPS guidance, off-route/stale/accuracy states, explicit foreground location controls, and rotation state retention. GPS sharing, persistence and background collection remain absent.
- Repeatable build/package/upload scripts, checksummed immutable regional data releases, separate 10 GiB homelab PVC, read-only/nonroot map services, Compose overlay, OpenAPI contract, ADR/license/runbook documentation.
- CI now includes Android lint. GitHub publishing follows successful same-source CI and prevents older sources from replacing newer releases.

## Verified so far

- Go vet/race tests: configuration guards, coordinate validation, routing adapter/geometry, unavailable service behavior, tile/glyph validation and privacy redaction pass.
- The full local `make ci` gate passes. Final targeted Go and Android build/test/lint checks also pass; four route-progress unit tests run; version-update warnings are retained rather than changing the established toolchain during the spike.
- Regional import and five local route/tile/glyph smoke checks passed; [measurements and samples](../navigation-evaluation.md).
- On the physical Android 17 phone over paired TLS Wi-Fi ADB: update/install, map with roads and labels, route overlay/instructions, guidance refusal without a fresh location, labeled simulated playback, landscape/portrait playback and stopping playback passed. The final 4.4 km surface-road sample, corrected full-route fit, and background/resume were also checked on-device. No crash entries appeared for the checked app processes.
- The user enabled Android location permission. The stationary check reported a stale fix; live GPS following is **not verified**. A fresh app process started with location collection off. Device coordinates were not printed or committed.
- Map-data upload to the operator-owned homelab PVC passed every SHA-256 check. Live map-service deployment and post-release checks are being completed; update this report only with actual results.
