# M0 physical-device smoke test

Tested 2026-11-13 on a Samsung SM-S947B, Android 17 / API 37, arm64-v8a, 1440×3120 display. Source: `0c0bd71`. App: `org.projectdrive.app`, version 0.1.0 (1), min SDK 26 / target 36. APK SHA-256: `1f31315c13bf805d0ceefbf29b888229888ae189fd300974a15d1b7c909ec523`.

The workstation paired using Android's TLS wireless debugging and selected the Wi-Fi ADB transport explicitly. Pairing codes, serial numbers and network addresses are excluded from this report.

| Check | Result |
| --- | --- |
| Gradle `:app:assembleDebug` | Passed |
| Install/update over Wi-Fi (`adb install -r`) | Passed |
| Cold launch (`am start -S -W`) | Passed; Android reported 324 ms total, one stationary sample |
| UI hierarchy and screenshot | “Project Drive” and “M0 developer shell” visible; app resumed |
| Home, then resume | Passed |
| Rotate to landscape | Passed; hierarchy rotation 1, screenshot 3120×1440 |
| Restore portrait | Passed; original rotation lock restored |
| Force-stop and relaunch | Passed; Android reported 302 ms total, one stationary sample |
| App-process crash buffer | No entries for the tested processes |

These are startup/lifecycle smoke checks on one real device, not a performance benchmark or a navigation/location test. The M0 app requests no network or location permissions. No app data was cleared. Local screenshots and machine-readable test results were retained outside Git in `/tmp/project-drive-device-test/`.

For another session, follow [Android's wireless-debugging instructions](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi), select the connected Wi-Fi serial with `adb -s`, build with `make android-build`, install `apps/android/app/build/outputs/apk/debug/app-debug.apk`, and launch `org.projectdrive.app/.MainActivity`. Use the device's current connection port, which differs from its temporary pairing port.
